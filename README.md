# キャラページ工房 — CHARACTER PAGE WORKSHOP

テンプレを選んで画像と設定を入れるだけで、AFTERIMAGE風・ABYSS風の
キャラ紹介サイトが作れるサービスです。
公開ボタンを押すと、その場で「みんなが作ったページ」に公開され、
専用リンクをコピーしてシェアできます。

公開までの手順は **SETUP.md** に、やさしい言葉で書いてあります。

## ファイル一覧

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の土台（トップ／作る／マイページ／ログイン／ビューア） |
| `style.css` | 見た目全部（サービステーマ、公開ページのテンプレ×UIテンプレ、演出アニメーション） |
| `app.js` | 本体（アカウント、一覧、編集、保存、公開、リンクコピー） |
| `viewer.js` | 公開ページの描画と、開く／戻る演出 |
| `config.js` | Supabase の URL と anon key を貼る場所（ここだけ直せば本番になります） |
| `supabase_setup.sql` | Supabase に貼るだけのセットアップSQL（pages テーブル＋安全設定） |
| `SETUP.md` | 公開までの手順書 |
| `README.md` | このファイル |

## 仕組み

- サイト本体は GitHub Pages に置く静的なページです。
- アカウント・作品・画像の保存は Supabase（無料）を使います。
- `config.js` が空のあいだは **DEMOモード** で動きます。
  DEMOモードではアカウントも作品も、その端末のブラウザの中（localStorage）にだけ
  保存される試作用モードで、画面の上に黄色い帯でそのことを表示します。
  他の人と共有はできません。

## できること（仕様 v1）

- サイトテンプレ 2種：AFTERIMAGE風（記録アーカイブ型）／ABYSS風（監視ターミナル型）
- UIテンプレ 5種：記録ファイル型／監視端末型／ポスター型／本棚・手帳型／シンプル綺麗型
  （サイトテンプレとは別に選べて、組み合わせ自由）
- 演出：開く5種（グリッチ＋名前ドーン／CONNECTING／表紙せり上がり／残像フラッシュ／ページめくり）、
  戻る5種（RECORD CLOSED／シャッター／SIGNAL LOST／残像フェード／ページめくり）を別々に選択可能
- 編集項目：サイト全体（タイトル／作者名／紹介文／テーマカラー／背景画像／WORLD／ABOUT）、
  キャラ（名前／読み／英名／番号／画像＋ギャラリー／イメカラ／キャッチコピー／セリフ集／
  年齢・性別・身長／性格／設定文／好きなもの・苦手なもの／危険度・クラス／相関）、
  自由項目（名前を自分で付けられる項目の追加・削除・非表示）、使わない項目の非表示
- キャラの追加・削除・並び替え、画像アップロード（自動で最大1200pxに縮小して保存）
- 公開／非公開の切り替え、削除、リンクコピー（`#/view/<id>` 形式、`?view=<id>` でも開けます）
